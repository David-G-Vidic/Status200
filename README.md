# JMeter Testing Group Project (Incomplete)

## Description

Performance testing of a Todo application using Apache JMeter to evaluate responsiveness, throughput, and stability under varying user loads.

## Project Status

The project was assigned as part of Revature's training program for the Performance Testing Engineer role.
During this project, our class was moved to a new training program to accommodate business needs. As a result, we did not complete this project. 

## About

This project uses Apache JMeter to evaluate the performance and reliability of a Todo application across user registration, authentication, and todo/subtask management workflows. It demonstrates performance testing practices by simulating varying user loads, measuring response times, throughput, error rates, and identifying potential bottlenecks. The goal is to assess application behavior under different workloads and document findings and recommendations for improvement.

## Tech Stack

- **Languages:** Java, SQLite
- **Tools:** JMeter, DBeaver, Git
